# `uu` Umbrella CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One discoverable, beginner-friendly, agent-usable command (`uu`) fronting every uumami_os operation, plus the ~50-alias annotated catalog — per the approved spec `docs/superpowers/specs/2026-07-01-uu-cli-design.md`.

**Architecture:** `setup/bin/uu` is a single bash dispatcher — a **pure deterministic facade**: every verb routes to an existing `setup/lib/*.sh` script or composes documented podman/distrobox one-liners; no business logic lives in `uu`. Context-aware (host vs in-box via `/run/.containerenv`, host verbs auto-prefix `distrobox-host-exec`). Aliases live in `setup/templates/qol/aliases.sh` with `# @<category>: <desc>` annotations that `uu aliases` renders.

**Tech Stack:** bash (shellcheck-clean), podman/distrobox, yq only where the repo already requires it (host-side registry), zero new dependencies (JSON emitted by a built-in escaper — deviation from the spec's "yq -o=json" note, recorded in Task 10).

## Global Constraints

- Exit codes: `0` done · `2` human-required (instructions printed) · `3` precondition failed · `1` error.
- Bare `uu` prints help and exits 0 — never an error. Every failure path ends with a `hint:` line.
- Forbidden vocabulary — these strings must NOT appear in `setup/bin/uu` except in help text warning against them: `prune -a`, `--rm-home`. `uu` never writes under `~/Profiles` or `~/Models` content except `tenant rm --profile` (name-retype gated).
- Mutating verbs (`clean`, `recreate`, `tenant new`, `tenant rm`): explain-plan → confirm; `--yes` skips confirm; `--dry-run` prints plan, exits 0. Plan format: `would:` / `keeping:` (with reason) / `untouched:` lines.
- `uu` never calls a model or agent (deterministic guarantee, stated in `help --agent`).
- All scripts pass `shellcheck -x -S warning` with zero output.
- Alias annotation format (exact): trailing comment `# @<category>: <description>` on the same line as the alias/function. Categories: `agents git gh tmux containers llm`.
- Every task ends with a commit; commit messages end with `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`.
- Run everything from repo root `/run/host/var/home/uumami/Code/system/uumami_os` (inside os_agent; host commands via `distrobox-host-exec`).

```bash
mkdir -p setup/bin
cat > setup/bin/uu <<'UUEOF'
#!/usr/bin/env bash
# uu — uumami_os umbrella CLI. DETERMINISTIC FACADE: every verb routes to an existing
# setup/lib script or composes documented podman/distrobox one-liners. No business logic
# here; uu never calls a model or agent. Spec: docs/superpowers/specs/2026-07-01-uu-cli-design.md
# Exit codes: 0 done · 2 human-required (instructions printed) · 3 precondition failed · 1 error.
set -uo pipefail
UU_VERSION="1.0.0"

# ---------- core helpers ----------
die()  { printf 'uu: %s\n' "$1" >&2; [ -n "${2:-}" ] && printf 'hint: %s\n' "$2" >&2; exit "${3:-1}"; }
pre()  { die "$1" "${2:-}" 3; }
have() { command -v "$1" >/dev/null 2>&1; }
in_box()   { [ -f /run/.containerenv ]; }
box_name() { sed -n 's/^name="\(.*\)"/\1/p' /run/.containerenv 2>/dev/null; }
host_run() { if in_box; then distrobox-host-exec "$@"; else "$@"; fi; }
json_escape() { local s=${1//\\/\\\\}; s=${s//\"/\\\"}; s=${s//$'\n'/ }; s=${s//$'\t'/ }; printf '%s' "$s"; }

repo_root() {
  if [ -n "${UU_REPO:-}" ] && [ -d "$UU_REPO/setup/lib" ]; then printf '%s' "$UU_REPO"; return 0; fi
  local self cand
  self="$(readlink -f "${BASH_SOURCE[0]}" 2>/dev/null || printf '%s' "${BASH_SOURCE[0]}")"
  cand="$(cd "$(dirname "$self")/../.." 2>/dev/null && pwd)" || cand=""
  [ -n "$cand" ] && [ -d "$cand/setup/lib" ] && { printf '%s' "$cand"; return 0; }
  for cand in "$HOME/Containers" "$HOME/Code/system/uumami_os"; do
    [ -d "$cand/setup/lib" ] && { printf '%s' "$cand"; return 0; }
  done
  return 1
}
need_repo() {
  REPO="$(repo_root)" || pre "this verb needs the uumami_os repo (setup/lib), which is not reachable" \
    "set UU_REPO=/path/to/repo, or run this verb from the admin account"
}

# ---------- verb registry ----------
ALL_VERBS=(status enter work tenant models clean rebuild recreate build logs github \
           bootstrap validate doctor aliases help)

verb_summary() {
  case "$1" in
    status)    echo "everything at a glance: boxes, llm service/GPU, disk, pending recreates" ;;
    enter)     echo "enter a box (default: os_agent)" ;;
    work)      echo "launch a named session inside this box (work --list to see them)" ;;
    tenant)    echo "isolated project spaces: new / ls / rm" ;;
    models)    echo "models on the shared server: ls / pull / rm" ;;
    clean)     echo "safe disk cleanup (dangling images only; plan shown first)" ;;
    rebuild)   echo "rebuild dev_base + derived images; prints recreate steps" ;;
    recreate)  echo "recreate one box from its image (profile survives)" ;;
    build)     echo "assemble + build one image (dev_base, os_agent, per-project)" ;;
    logs)      echo "llm_server journal (add -f to follow)" ;;
    github)    echo "finish the per-profile GitHub SSH setup" ;;
    bootstrap) echo "first-time setup: probe machine, match flavor, validate config" ;;
    validate)  echo "fast check: is my config/flavors correct?" ;;
    doctor)    echo "full health check (selftest; --quick to skip heavy checks)" ;;
    aliases)   echo "show the shell-alias catalog (uu aliases agents|git|gh|tmux|containers|llm)" ;;
    help)      echo "this screen; 'uu help <command>' for details + examples" ;;
    *)         return 1 ;;
  esac
}

agent_help() {
  cat <<EOF
uu machine contract (v$UU_VERSION) — deterministic: uu NEVER calls a model or agent; output
is ground truth about the system.
EXIT CODES: 0=done 2=human-required(instructions were printed) 3=precondition-failed 1=error
MUTATING VERBS (clean, recreate, tenant new, tenant rm): --dry-run prints the plan (exit 0);
--yes skips confirmation. Plan lines are prefixed: 'would:' 'keeping:' 'review:' 'untouched:'.
tenant rm --profile ALWAYS prompts for the tenant name retype, even with --yes.
READ VERBS with --json (stable keys, no ANSI): status, tenant ls, models, aliases.
FORBIDDEN BY VOCABULARY: prune -a, --rm-home, writes under ~/Profiles or ~/Models content.
VERBS:
EOF
  local v; for v in "${ALL_VERBS[@]}"; do printf '  %-10s %s\n' "$v" "$(verb_summary "$v")"; done
}

suggest() {  # did-you-mean for an unknown verb
  local bad="$1" v out=""
  for v in "${ALL_VERBS[@]}"; do
    case "$v" in "$bad"*|*"$bad"*) out="$v"; break;; esac
  done
  [ -z "$out" ] && case "$bad" in
    rm|remove|delete) out="tenant rm";; new|create|add) out="tenant new";;
    ls|list) out="status";; model) out="models";; alias) out="aliases";;
    check|test) out="doctor";; update|upgrade) out="rebuild";;
  esac
  [ -n "$out" ] && printf 'did you mean: uu %s ?\n' "$out" >&2
  printf 'hint: run `uu` for the command list\n' >&2
}

cmd_help() {
  local topic="${1:-}"
  case "$topic" in
    "")        overview ;;
    --agent)   agent_help ;;
    *)         verb_help "$topic" || { printf 'uu: no help topic "%s"\n' "$topic" >&2; suggest "$topic"; exit 1; } ;;
  esac
}

# ---------- dispatcher ----------
main() {
  [ "$#" -eq 0 ] && { overview; exit 0; }
  local verb="$1"; shift
  case "$verb" in
    -h|--help|help) cmd_help "${1:-}"; exit 0 ;;
    -v|--version)   echo "uu $UU_VERSION"; exit 0 ;;
  esac
  # per-verb --help
  for a in "$@"; do [ "$a" = --help ] && { verb_help "$verb" || true; exit 0; }; done
  case "$verb" in
    status|enter|work|models|clean|rebuild|recreate|build|logs|github|bootstrap|validate|doctor|aliases)
      "cmd_$verb" "$@" ;;
    tenant)
      local sub="${1:-}"; shift || true
      case "$sub" in
        new|ls|rm) "cmd_tenant_$sub" "$@" ;;
        --help|"") verb_help tenant; exit 0 ;;
        *) printf 'uu: unknown tenant subcommand "%s"\n' "$sub" >&2
           printf 'hint: uu tenant new|ls|rm — see `uu help tenant`\n' >&2; exit 1 ;;
      esac ;;
    *)
      printf 'uu: unknown command "%s"\n' "$verb" >&2; suggest "$verb"; exit 1 ;;
  esac
}
```

```bash
# ---------- status / logs ----------
drift_of() {  # container image -> yes|no|unknown (image newer than container = recreate pending)
  local cc ic cs is
  cc="$(host_run podman inspect "$1" --format '{{.Created}}' 2>/dev/null)" || { echo unknown; return; }
  ic="$(host_run podman image inspect "$2" --format '{{.Created}}' 2>/dev/null)" || { echo unknown; return; }
  cs="$(date -d "$cc" +%s 2>/dev/null || echo 0)"; is="$(date -d "$ic" +%s 2>/dev/null || echo 0)"
  if [ "$is" -gt 0 ] && [ "$cs" -gt 0 ] && [ "$is" -gt "$cs" ]; then echo yes; else echo no; fi
}

cmd_status() {
  local as_json=no; [ "${1:-}" = --json ] && as_json=yes
  local ctx="host"; in_box && ctx="box:$(box_name)"
  # boxes: name image (skip header)
  local boxes_raw; boxes_raw="$(host_run distrobox list --no-color 2>/dev/null | awk -F'|' 'NR>1{gsub(/ /,"",$2); gsub(/ /,"",$4); if($2!="") print $2, $4}')"
  # llm service + endpoint + processor
  local svc="inactive"; host_run systemctl --user is-active llm_server.service >/dev/null 2>&1 && svc="active"
  local endpoint="down" nmodels=0
  if curl -fsS --max-time 3 http://127.0.0.1:11434/api/tags -o /tmp/uu_tags.$$ 2>/dev/null; then
    endpoint="up"; nmodels="$(grep -o '"name"' /tmp/uu_tags.$$ | wc -l | tr -d ' ')"
  fi; rm -f /tmp/uu_tags.$$
  local proc; proc="$(host_run distrobox enter llm_server -- ollama ps 2>/dev/null | awk 'NR==2 && /GPU|CPU/ {for(i=1;i<=NF;i++) if($i ~ /GPU|CPU/) {print $(i-1), $i; exit}}')"
  [ -z "$proc" ] && proc="idle"
  # disk (Images row of podman system df)
  local disk; disk="$(host_run podman system df 2>/dev/null | awk '/^Images/{print $4" used, "$5" "$6" reclaimable"}')"
  # config validity (only when repo reachable)
  local cfg="unknown" r; r="$(repo_root)" && { bash "$r/setup/lib/validate.sh" >/dev/null 2>&1 && cfg=valid || cfg=INVALID; }
  if [ "$as_json" = yes ]; then
    printf '{"context":"%s","llm":{"service":"%s","endpoint":"%s","models":%s,"processor":"%s"},"disk":"%s","config":"%s","boxes":[' \
      "$(json_escape "$ctx")" "$svc" "$endpoint" "${nmodels:-0}" "$(json_escape "$proc")" "$(json_escape "${disk:-}")" "$cfg"
    local first=yes name img
    while read -r name img; do
      [ -z "$name" ] && continue
      [ "$first" = yes ] || printf ','; first=no
      printf '{"name":"%s","image":"%s","drift":"%s"}' "$(json_escape "$name")" "$(json_escape "$img")" "$(drift_of "$name" "$img")"
    done <<< "$boxes_raw"
    printf ']}\n'; return 0
  fi
  echo "context : $ctx"
  echo "llm     : service=$svc endpoint=$endpoint models=$nmodels processor=$proc"
  echo "disk    : ${disk:-n/a}"
  echo "config  : $cfg"
  echo "boxes   :"
  local name img d
  while read -r name img; do
    [ -z "$name" ] && continue
    d="$(drift_of "$name" "$img")"
    if [ "$d" = yes ]; then
      printf '  %-14s %-34s RECREATE PENDING (image is newer)\n' "$name" "$img"
    else
      printf '  %-14s %s\n' "$name" "$img"
    fi
  done <<< "$boxes_raw"
  if printf '%s' "$boxes_raw" | grep -q .; then :; else echo "  (none)"; fi
  echo
  echo "hint: uu help status · pending recreate? -> uu recreate <box> · unhealthy? -> uu doctor"
}

cmd_logs() {
  local args=(-u llm_server --no-pager -n 50)
  while [ "$#" -gt 0 ]; do case "$1" in
    -f) args+=(-f) ;; -n) shift; args+=(-n "${1:?-n needs a number}") ;;
    *) pre "unknown logs flag '$1'" "uu logs [-f] [-n N]" ;;
  esac; shift; done
  host_run journalctl --user "${args[@]}"
}
```

```bash
# ---------- models / tenant ls ----------
cmd_models() {
  local sub="${1:-ls}"; shift || true
  case "$sub" in
    ls|--json)
      if [ "$sub" = --json ] || [ "${1:-}" = --json ]; then
        curl -fsS --max-time 5 http://127.0.0.1:11434/api/tags 2>/dev/null \
          || pre "llm endpoint not responding" "uu logs · systemctl --user status llm_server"
        echo; return 0
      fi
      host_run distrobox enter llm_server -- ollama list 2>/dev/null \
        || pre "cannot reach llm_server box" "uu status · uu logs" ;;
    pull|rm)
      local m="${1:-}"; [ -n "$m" ] || pre "models $sub needs a model name" "uu models   # to see what exists"
      host_run distrobox enter llm_server -- ollama "$sub" "$m" ;;
    *) pre "unknown models subcommand '$sub'" "uu models [ls|pull|rm] — see \`uu help models\`" ;;
  esac
}

registry_path() {
  # profiles dir is only configurable via the repo config; default matches config.yaml
  printf '%s' "${UU_PROFILES:-$HOME/Profiles}/registry.yaml"
}

cmd_tenant_ls() {
  local as_json=no; [ "${1:-}" = --json ] && as_json=yes
```

```bash
DRY=no; YES=no; REST=()
parse_mut_flags() {
  DRY=no; YES=no; REST=()
  local a; for a in "$@"; do case "$a" in
    --dry-run) DRY=yes ;; --yes|-y) YES=yes ;; *) REST+=("$a") ;;
  esac; done
}
confirm_or_die() {
  [ "$YES" = yes ] && return 0
  printf '%s [y/N] ' "$1"
  local ans; read -r ans || ans=""
  case "$ans" in y|Y|yes|YES) return 0 ;; *) die "aborted (nothing was changed)" "add --dry-run to preview, --yes to skip this prompt" 1 ;; esac
}

cmd_clean() {
  parse_mut_flags "$@"
  # plan: dangling images (would remove) / in-use (keeping) / tagged-unused (review)
  local dangling; dangling="$(host_run podman images -f dangling=true --format '{{.ID}} {{.Size}}' 2>/dev/null)"
  local inuse;    inuse="$(host_run podman ps -a --format '{{.Image}}' 2>/dev/null | sort -u)"
  local tagged;   tagged="$(host_run podman images --format '{{.Repository}}:{{.Tag}}' 2>/dev/null | grep -v '^<none>' | sort -u)"

    echo "  would: remove dangling images — none found"

  while read -r t; do
```

```bash
      u="$(host_run bash -lc 'PATH="$HOME/.local/bin:$PATH" yq -r '\''(.tenants // [])[] | select(.name == "'"$box"'") | .user'\'' '"$reg"' 2>/dev/null')"
      [ -n "$u" ] || pre "unknown box '$box'" "uu status · uu tenant ls"
      cat <<EOF
[human-required] '$box' belongs to Linux user '$u'. As that user, rerun its setup:
  sudo -iu $u bash <repo>/setup/lib/tenant-create.sh --user-setup <manifest>
  (or: sudo -iu $u distrobox rm -f $box   # then rerun tenant-create user-setup)
EOF
      exit 2 ;;
  esac
}

cmd_tenant_new() {
  parse_mut_flags "$@"
  local name="" tier="" manifest="" i=0 n=${#REST[@]}
  while [ "$i" -lt "$n" ]; do
    case "${REST[$i]}" in
      --tier)     i=$((i+1)); tier="${REST[$i]:-}" ;;
      --manifest) i=$((i+1)); manifest="${REST[$i]:-}" ;;
      *) name="${REST[$i]}" ;;
    esac; i=$((i+1))
  done
  need_repo
  if [ -n "$manifest" ]; then
    [ -f "$manifest" ] || pre "manifest '$manifest' not found" "see setup/templates/tenant-example.yaml"
  else
    [ -n "$name" ] || pre "tenant new needs a name (or --manifest file)" "uu tenant new acme · see \`uu help tenant\`"
    case "$name" in *[!a-z0-9-]*) pre "name must be kebab-case (a-z, 0-9, -)" "e.g. uu tenant new acme-corp";; esac
    manifest="$(mktemp /tmp/uu-tenant-XXXX.yaml)"
    { echo "name: $name"; [ -n "$tier" ] && echo "tier: \"$tier\""
      echo "browser: per-tenant"
      echo "sessions:"; echo "  - {name: ${name}-main, agent: opencode, workdir: .}"
    } > "$manifest"
    echo "generated a minimal manifest ($manifest) — for full options copy setup/templates/tenant-example.yaml"
  fi
  local flags=(); [ "$DRY" = yes ] && flags+=(--dry-run)
  host_run bash "$REPO/setup/lib/tenant-create.sh" "${flags[@]}" "$manifest"
  local rc=$?
  [ "$rc" -eq 2 ] && echo "hint: run the printed sudo commands, then the --user-setup line (this is the ONLY sudo step)"
  return "$rc"
}

cmd_tenant_rm() {
  parse_mut_flags "$@"
  local name="" wipe_profile=no a
  for a in "${REST[@]}"; do case "$a" in
    --profile) wipe_profile=yes ;; *) name="$a" ;;
  esac; done
  [ -n "$name" ] || pre "tenant rm needs a name" "uu tenant ls"
  local reg profdir="$HOME/Profiles/$name"
  reg="$(registry_path)"
  echo "plan:"
  echo "  would: distrobox rm -f $name            (the box; its writable layer is freed)"
  echo "  would: remove '$name' from the registry ($reg)"
  if [ "$wipe_profile" = yes ]; then
    echo "  would: DELETE the profile $profdir     (credentials/sessions — NO UNDO)"
  else
    echo "  keeping: the profile $profdir (credentials survive; pass --profile to delete it)"
  fi
  echo "  untouched: models, code, other tenants"
  [ "$DRY" = yes ] && { echo "hint: run without --dry-run to apply"; return 0; }
  confirm_or_die "decommission tenant '$name'?"
  host_run distrobox rm -f "$name" 2>/dev/null || echo "  (no box named '$name' — continuing)"
  host_run bash -lc 'PATH="$HOME/.local/bin:$PATH" N='"$name"' yq -i '\''del(.tenants[] | select(.name == env(N)))'\'' '"$reg"' 2>/dev/null' || true
  echo "  box + registry entry removed."
  if [ "$wipe_profile" = yes ]; then
    # No-undo step: ALWAYS retype the name, even with --yes (spec §4).
    printf 'to DELETE the profile (no undo), retype the tenant name: '
    local typed; read -r typed || typed=""
    [ "$typed" = "$name" ] || die "name mismatch — profile NOT deleted" "profile kept at $profdir" 1
    [ -d "$profdir" ] || pre "no profile at $profdir (tier-2a profiles are the tenant user's home — remove via 'sudo userdel -r' deliberately)" ""
    host_run rm -rf -- "$profdir"
    echo "  profile deleted."
  fi
  echo "done. hint: if this was a tier-2a tenant, also (deliberately): sudo userdel -r <user> · their image store frees with: sudo -iu <user> podman image prune"
}
```
